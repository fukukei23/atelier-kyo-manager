# AI Analysis Pack for atelier-kyo-manager
This folder is optimized for analysis by AI models (like ChatGPT).

## 📖 推奨される分析手順

1.  **`PROJECT_CHRONICLE.md` (【推奨】ここから読む)**
    * Git履歴から生成されたプロジェクトの進化の物語。開発の文脈を理解できます。

2.  **`PROJECT_BLUEPRINT.md` (【推奨】次に読む)**
    * モジュール間の依存関係を可視化した構造設計図。

3.  **`PROJECT_INFO.md`**
    * プロジェクトの統計情報と完全なディレクトリ構造。

4.  **`source_code/` (【重要】分析対象)**
    * **元のディレクトリ構造を維持したソースコード一式。**

## 💡 ChatGPT へのアップロード方法
1. このフォルダ（`README.md` がある場所）を開きます。
2. **フォルダ内の全ファイルとフォルダ (`PROJECT_...`, `source_code/` 等）をすべて選択** してください。
3. ChatGPTのチャット入力欄に、選択したファイル群を**まとめてドラッグ＆ドロップ**します。
4. アップロードが完了したら、分析を開始してください。

5.  **`README.md` (このファイル)**
