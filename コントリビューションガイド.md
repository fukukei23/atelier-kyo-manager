# Contributing Guide



Thank you for considering contributing to Atelier Kyo Manager.



## How to contribute



- For major changes, please open an issue first to discuss what you would like to change.

- Open pull requests against a dedicated branch (not directly on main).

- Add tests where applicable.

- Follow the existing directory conventions and style.



## Code Style



- Python: Black, isort, Ruff（必要に応じて）

- Commit messages: Conventional Commits を推奨



## Pull Requests



- 1 PR = 1 Feature or Fix

- Include screenshots when UI changes are involved

- Describe the motivation and impact clearly
