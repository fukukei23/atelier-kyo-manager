## 1. ビジョンステートメント

**「BUYMAショッパーの、最もわかりにくく・時間のかかる作業をゼロにする」**

atelier-kyo-managerは、BUYMAでの「海外公式ブランドサイト仕入れ」に特化した無在庫販売支援ツールです。
複雑な利益計算、煩雑な出品作業、ペナルティリスクを伴う発送管理という、無在庫販売における最大のペインを自動化・最適化します。

まずは開発者自身がBUYMAショッパーとしてツールを使い込み、月商30万円という結果を出すことで現場での実用性を証明します。その後、この成功モデルをSaaSとして提供し、同じ仕入れ手法をとる他のショッパーにも利益が出る商品の迅速な特定と業務効率化を提供します。

---

## 2. 解決する課題

BUYMAにおける「海外公式サイトからの無在庫販売」において、以下の5つの課題を解決します。

1. **利益計算の複雑さ**: 仕入れ価格、転送送料、関税、BUYMA手数料を加味した利益計算を手作業で行うのは誤差が生じやすく、損失リスクが高い
2. **価格比較の非効率性**: 海外ブランド公式サイトとBUYMAの相場を手作業で確認・比較する作業は、時間あたりの生産性が極めて低い
3. **出品作業の重工数**: 商品画像の加工（背景除去など）や、販売用説明文の作成に膨大な時間を要する
4. **18日発送ルールの管理の煩雑さ**: 受注から18日以内の発送というルールの管理を怠ると、アカウント停止等のペナルティリスクとなる
5. **顧客対応（CS）の時間浸食**: ショッパーの貴重な作業時間が、問い合わせ対応によって奪われる

## 3. ターゲットユーザー

### フェーズ1: ファーストユーザー（個人検証期）
- **開発者自身（BUYMAショッパー）**
- 物販未経験だが、ツール開発力を活かして「海外公式サイトからの無在庫転売」を自動化・最適化し、自身の収益化を目指す
- 資金: 約100万円、開発時間: 週10-20時間

### フェーズ2: 将来ターゲット（SaaS化期）
- **BUYMAで無在庫販売を行う他のショッパー**
- 特に「海外ブランド公式サイトから直接仕入れる」モデルを採用している、または導入したい層
- 月額 9,800円〜29,800円 の料金体系を想定

## 4. 提供価値

| 価値 | 説明 |
|------|------|
| 利益が出る商品の迅速な特定 | 複雑なコスト計算を一瞬で実行し、差益が見込める商品を自動抽出 |
| 出品作業の自動化 | AI画像処理（背景除去）とテキスト生成で出品時間を劇的短縮 |
| 売上・利益の可視化 | 収益性をリアルタイムに把握し、データドリブンな仕入れ判断を支援 |
| 18日ルール・在庫管理の自動化 | 受注からのカウントダウンや在庫切れを監視し、ペナルティリスクを回避 |

## 5. 成功指標

### フェーズ1（個人検証）
- **月商30万円達成**: ツールを活用した無在庫販売で月商30万円の利益基盤を構築

### フェーズ2（SaaS化準備・ローンチ）
- **CS工数79%削減**: 自店舗での運用を通じて顧客対応工数を79%削減した実績
- **SaaS顧客獲得**: 月額9,800円〜29,800円で5〜10社の有料ユーザー獲得

---

## 6. 差別化要因

1. **「現場発の実用性」**: 開発者自身がショッパーとして使い込み、実際に利益を出してからSaaS化する
2. **仕入れルートの特化**: 「海外ブランド公式サイト → 転送倉庫」に深く最適化
3. **BUYMA専用設計**: 汎用ECツールではなく、BUYMAの仕様（手数料体系、18日ルール等）に完全特化

## 8. リスクと制約

| リスク | 影響度 | 対策 |
|--------|--------|------|
| BUYMA規約変更 | 高 | 規約の定期監視、複数プラットフォーム対応の余地を残す設計 |
| スクレイピングブロック | 高 | Bright Data継続試行 + 半手動フォールバック |

| ソロ開発のリソース制約 | 中 | 週10-20hに集中、MVP優先 |
| 転送倉庫のコスト変動 | 中 | 複数倉庫サービスの比較・切替可能な設計 |
