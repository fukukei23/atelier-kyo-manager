# 1ページ目｜表紙・重要注意（確定版）

# BUYMA無在庫
# 半自動 出品準備補助ツール

ローカル実行型／CSV生成・利益確認・説明文下書き

## 本ツールについて（最重要）

本ツールは、
BUYMA無在庫出品における「出品準備作業」を標準化・簡略化するための補助ツールです。

以下の行為は 一切行いません。

- BUYMAへのログイン
- 商品の自動出品
- 在庫監視・価格自動変更
- アカウント操作・出品代行

出品の最終判断・操作は、すべて利用者自身が行います。

## このツールの位置づけ

- 本ツールは 出品準備の補助です
- 利益・可否の判断を代行するものではありません
- 生成される内容は 参考情報・下書きに留まります
- BUYMAの利用規約を遵守する責任は、
  すべて利用者自身にあります。

## 想定利用者

- BUYMA無在庫出品を行っている、または検討している方
- 出品準備を「毎回ゼロから考える」状態から脱却したい方
- 自動化よりも 安全性・再現性・判断のしやすさを重視する方

## ご注意（必ずお読みください）

- 本ツールは 利益を保証するものではありません
- BUYMAからの警告・停止・アカウント制限等について
  開発者は責任を負いません
- 本ツールの利用によって生じたいかなる損害についても、
  最終的な責任は利用者に帰属します

# 2ページ目｜できること／できないこと（線引きページ・確定版）

## このツールで「できること」

本ツールは、BUYMA無在庫出品における
出品準備作業を効率化・標準化するための補助ツールです。

具体的には、以下のことができます。

### 1. 出品用CSVの生成

- 商品情報CSVをもとに
  BUYMA出品用CSVを生成します
- CSVは「最終提出用」ではなく
  確認・調整前提の中間成果物です

### 2. 利益計算・判断補助

- 入力された仕入価格・送料・為替・想定販売価格から
  利益額・利益率を算出します
- 利益が未確定な場合は
  partial（未確定）として明示されます
- 利益判断は あくまで補助であり、最終判断は利用者が行います

### 3. 説明文の下書き生成（任意）

- OpenAI APIを利用し
  商品説明文の下書きを生成します
- 生成結果は 必ず人が確認・修正してください
- 規約回避・誇張・断定表現は 禁止です

### 4. 画像の最低限整形

- 画像サイズの調整
- ファイル名の整理
- ※ 演出・加工・誇張は行いません

## このツールで「できないこと」（重要）

以下の行為は 設計上、明確に除外されています。

### ❌ 出品操作に関すること

- BUYMAへのログイン
- 商品の自動出品
- 出品情報の直接登録
- 出品代行

### ❌ アカウント・監視系

- 在庫自動監視
- 価格の自動変更
- アカウント情報の取得・保存・操作

### ❌ 自動化・回避行為

- ブラウザ自動操作
- スクレイピング強化
- 規約回避を目的とした挙動

## なぜ「できないこと」があるのか

これらを含めると、以下のリスクが急激に高まります。

- BUYMA規約違反
- アカウント停止（BAN）
- 誤操作による損害
- 情報漏えい

本ツールは
「安全に・長く使える」ことを最優先に設計されています。

## 本ツールの立ち位置（再確認）

- 出品準備を 毎回ゼロから考えないための道具
- 判断を 速く・整理しやすくするための補助
- 出品行為そのものを 代行・自動化しない

# 3ページ目｜全体フロー（1商品分の出品準備）

## 出品準備の全体像

本ツールを使った 1商品分の出品準備は、
以下の 6ステップで完了します。

※ このフローは 毎回同じ順序で実行することを前提に設計されています。

## Step 1｜商品情報CSVを用意する

出品したい商品の情報を
指定フォーマットのCSVに入力します

必須項目・任意項目は後述します

この時点では、
BUYMAの管理画面を開く必要はありません。

## Step 2｜コマンドを1回実行する

ターミナル（コマンドプロンプト）で
以下のように 1コマンドを実行します。

```
python -m app.utils.sourcing_csv_runner --csv 入力CSV.csv --row 0
```

- `--csv`：入力CSVのパス
- `--row`：処理したい行番号（0始まり）

## Step 3｜出力ファイルが生成される

コマンド実行後、以下のファイルが生成されます。

- 出品用CSV
- 利益計算結果（profitability）
- Tier判定結果（tier_judgement）
- 実行ログ

これらは 自動生成される中間成果物です。

## Step 4｜利益・Tierを確認する

生成された結果を確認し、以下を判断します。

- 利益額は許容範囲か
- 利益率は問題ないか
- Tier（A/B/C）は想定どおりか

※ 不足情報がある場合は
partial（未確定）として明示されます。

## Step 5｜説明文の下書きを確認・修正する

説明文下書きが生成されている場合：

- 内容を必ず人が確認
- 表現の誇張・断定がないかを確認
- BUYMA規約に反しないかを確認

そのまま使うことは推奨されません。

## Step 6｜人が最終判断し、BUYMAへ提出する

最終的に：

- 出品するかどうか
- 価格をどうするか
- 説明文・画像をどう調整するか

これらは すべて利用者自身が判断し、
BUYMA管理画面から 手動で出品します。

## 本フローの設計意図

- 出品準備を 毎回ゼロから考えない
- 判断ポイントを 見える化する
- 自動化による事故を 構造的に避ける

本ツールは
**「考える負担を減らし、判断は残す」**ための道具です。

# 4ページ目｜動作環境と事前準備

## 動作環境

本ツールは ローカル実行型です。
サーバー運用や常時接続は必要ありません。

### 対応OS

- Windows
- macOS
- Linux

※ 一般的な個人利用環境を想定しています。

## 必要なソフトウェア

### Python

- Python 3.10 以上を推奨
- 確認方法（ターミナル／コマンドプロンプト）：

```
python --version
```

### 仮想環境（推奨）

- venv 等の仮想環境での実行を推奨します
- グローバル環境での実行も可能ですが、推奨しません

### OpenAI API キー（任意）

説明文の下書き生成機能を使用する場合のみ、
OpenAI API キーが必要です。

#### 注意点

- APIキーは 利用者自身が取得・管理してください
- 本ツールは APIキーを保存・共有しません
- API利用に伴う費用は 利用者負担です

※ 説明文生成を使わない場合、APIキーは不要です。

## BUYMAアカウントについて

- BUYMAアカウントは 本ツールでは使用しません
- ログイン情報の入力・保存は 一切ありません
- 出品作業は、
  最終ステップで利用者自身がBUYMA管理画面から行います。

## 事前に用意するもの（まとめ）

- Python 実行環境
- 商品情報CSV
- （任意）OpenAI APIキー
- BUYMA出品に必要な基本知識

## セキュリティ上の設計意図

- アカウント情報を扱わない
- 常時起動しない
- 外部サーバーを使用しない

これにより、
情報漏えい・誤操作・BANリスクを構造的に低減しています。

# 5ページ目｜ディレクトリ構成と触ってよい場所／触らない場所

## ディレクトリ構成の考え方

本ツールは、
「触ってよい場所」と「触ってはいけない場所」を明確に分けることで、
誤操作や事故を防ぐ設計になっています。

以下では、最低限理解すべきディレクトリ構成のみを説明します。

## 触ってよい場所（利用者が操作する範囲）

### app/utils/

- 本ツールの 商品本体
- CSV処理、利益計算、出力生成などの処理が含まれます
- 通常、内容を編集する必要はありません

### tests/fixtures/

- サンプルCSVが格納されています
- 入力CSV作成時の 参考用

### docs/reports/

- コマンド実行時のログや結果レポートが出力されます
- エラー時の確認に使用します

### 任意の作業用ディレクトリ

- 入力CSVは、任意の場所に置いて問題ありません
- 出力CSVも、指定した場所に生成されます

## 原則として触らない場所（重要）

以下のディレクトリ・ファイルは、
内容を変更しないでください。

### app/__init__.py

- 商品版では 最小構成になっています
- Web機能を意図的に無効化しています
- 編集すると、動作しなくなる可能性があります

### non_product/

- 研究・検証・非商品機能を隔離した領域です
- 商品版の動作には 一切関係ありません
- 内容を変更しても、商品機能は増えません

### tests/

- 動作確認用のテストコードです
- 通常利用では編集不要です

## なぜ「触らない場所」があるのか

- 商品思想と衝突する機能を混入させないため
- Web化・自動化への誤解を防ぐため
- 利用者自身の事故を防ぐため

本ツールは
「安全に使い続けられること」を優先しています。

## 困ったときの基本方針

- 迷ったら 編集しない
- 分からないファイルは 触らない
- エラー時は ログ（docs/reports）を確認
