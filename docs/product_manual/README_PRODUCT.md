# BUYMA無在庫・半自動出品準備補助ツール

このリポジトリは、
BUYMA無在庫出品における「出品準備作業」を標準化するためのローカル実行型ツールです。

**出品そのものを自動化するツールではありません。**
判断・最終操作は、すべて利用者自身が行います。

## これは何か（1分要約）

本ツールでできることは、以下に限定されています。

- 出品用CSVの生成
- 利益計算・Tier判定による判断補助
- 説明文の下書き生成（任意）
- 画像の最低限整形

**BUYMAへのログイン・自動出品・在庫監視は行いません。**

## できること / できないこと（重要）

### できること

- 出品準備を「毎回ゼロから考えずに」進める
- 利益条件・不確実性を整理する
- 判断ポイントを見える化する

### できないこと

- 自動ログイン
- 自動出品
- 在庫・価格の自動監視
- 出品代行・アカウント操作

本ツールは
**安全性・再現性・継続性を優先した設計**です。

## 想定利用者

- BUYMA無在庫出品を行っている、または検討している方
- 自動化よりも 事故を避けたい方
- 判断の摩耗を減らしたい方

## 基本的な使い方（概要）

1. 商品情報CSVを用意
2. コマンドを1回実行
3. 出力結果を確認
4. 人が最終判断し、BUYMAへ手動で出品

詳細な手順は
**商品正本マニュアル（manual.md）**に記載しています。

## 必ずお読みください（免責・注意）

- 本ツールは出品代行ではありません
- 利益・成果を保証するものではありません
- BUYMA規約遵守は 利用者自身の責任です
- 生成物は 参考情報・下書きです
