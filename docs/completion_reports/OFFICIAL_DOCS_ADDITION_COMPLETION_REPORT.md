## 概要

Atelier Kyo Manager の公式設計ドキュメントを整備し、プロジェクトの設計思想・アーキテクチャ・DBスキーマ・外部連携仕様を明確化しました。また、コントリビューションガイド・行動規範・セキュリティポリシーを追加し、オープンソースプロジェクトとしての基盤を整備しました。
