# テスト結果ファイルについて

## 概要

このプロジェクトでは、pytest を実行すると自動的にテスト結果が `docs/reports/` ディレクトリに保存されます。

## 保存されるファイル

- **ファイル名**: `TEST_RESULTS_YYYYMMDD_HHMMSS.txt`
- **保存場所**: `docs/reports/`
- **保存タイミング**: テスト実行終了時（成功・失敗に関わらず）

## ファイル内容

テスト結果ファイルには以下の情報が含まれます：

1. **実行情報**
   - 実行日時
   - 終了日時
   - 実行時間

2. **テスト統計**
   - 総テスト数
   - 成功数
   - 失敗数
   - スキップ数
   - 終了コード

3. **失敗テストの詳細**
   - 失敗したテストの名前
   - エラーメッセージとトレースバック

## 使い方

通常通り pytest を実行するだけで、自動的に結果ファイルが生成されます：

```bash
# すべてのテストを実行
pytest

# 特定のテストファイルを実行
pytest tests/test_plp_driver.py

# 詳細な出力付きで実行
pytest -v

# 長いトレースバックで実行
pytest --tb=long
```

結果ファイルは自動的に `docs/reports/` に保存されます。

## 設定

テスト結果の自動保存機能は `tests/conftest.py` で実装されています。

- 保存先を変更する場合は `tests/conftest.py` の `pytest_configure` を編集
- 保存形式を変更する場合は `pytest_sessionfinish` を編集

## 注意事項

- テスト結果ファイルは上書きされません（タイムスタンプ付き）
- 古い結果ファイルは手動で削除してください
- `.gitignore` に追加することを推奨（オプション）
