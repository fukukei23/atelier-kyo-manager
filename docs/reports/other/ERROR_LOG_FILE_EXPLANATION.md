# エラーログのファイル出力について

**作成日時**: 2025-11-30

---

## 現在の状況

✅ **エラーログは既にファイルに自動保存されています**

### 保存場所

- **テスト結果ファイル**: `docs/reports/TEST_RESULTS_YYYYMMDD_HHMMSS.txt`
- **自動生成**: テスト実行のたびに新しいファイルが作成されます

### 確認方法

```bash
# 最新のテスト結果ファイルを確認
ls -lt docs/reports/TEST_RESULTS_*.txt | head -1

# ファイルの内容を表示
cat $(ls -t docs/reports/TEST_RESULTS_*.txt | head -1)
```

---

## ファイルに含まれる内容

現在、`TEST_RESULTS_*.txt`ファイルには以下の情報が含まれます：

1. **実行日時**: テストの開始・終了時刻
2. **実行時間**: テストの実行時間（秒）
3. **テスト数**: 収集されたテスト数、実行されたテスト数
4. **結果**: 成功・失敗・スキップの数
5. **失敗したテストの詳細**: `longrepr`（エラーメッセージとスタックトレース）

---

## 問題点と改善案

### 現在の問題

テスト結果ファイルに「実行されたテスト数: 0」と表示される場合があります。これは`pytest_runtest_logreport`フックが正しく動作していない可能性があります。

### より詳細なエラーログを取得する方法

#### 方法1: pytest のログを直接ファイルにリダイレクト（推奨）

```bash
# テスト実行と同時にログをファイルに保存
pytest tests/test_product_extractor.py::test_product_extractor_moncler_pdp_sample \
  -xvs --tb=long > /tmp/pytest_error.log 2>&1

# エラーログを確認
cat /tmp/pytest_error.log
```

#### 方法2: WSL環境で直接実行（最も詳細）

WSL環境に直接ログインして実行すると、ターミナルに詳細なエラーが表示されます：

```bash
# WSLにログイン
wsl

# プロジェクトディレクトリに移動
cd /home/yn441611/atelier-kyo-manager
source venv/bin/activate

# テスト実行（詳細な出力）
pytest tests/test_product_extractor.py::test_product_extractor_moncler_pdp_sample -xvs --tb=long
```

この方法では、**ターミナルに詳細なエラーメッセージとスタックトレースが直接表示されます**。

#### 方法3: テスト結果ファイルを確認

```bash
# 最新のテスト結果ファイルを確認
latest_file=$(ls -t docs/reports/TEST_RESULTS_*.txt | head -1)
cat "$latest_file"
```

## 推奨される使用方法

### 最も詳細なエラーログを取得するには

1. **WSL環境に直接ログイン**
2. **テストを実行**（ターミナルに直接出力される）
3. **必要に応じてログをファイルにリダイレクト**

```bash
# WSLで実行
pytest tests/test_product_extractor.py::test_product_extractor_moncler_pdp_sample \
  -xvs --tb=long | tee /tmp/pytest_full_output.log
```

これにより、ターミナルに出力されると同時に、`/tmp/pytest_full_output.log`にも保存されます。
