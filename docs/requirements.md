# atelier-kyo-manager 要件定義書

**日付**: 2026-04-16
**ステータス**: ドラフト（MVP開発フェーズ）
**目的**: 本システムの「何を作るか」を明確に定義し、開発の指針とする

---

## 1. システム概要

atelier-kyo-managerは、海外公式ブランドサイトから転送倉庫を経由してBUYMAへ出品する「無在庫転売モデル」に特化した業務管理・自動化システム。

利益最大化と業務効率化を実現するため、価格計算、在庫管理、画像処理、AIによる価格最適化などを統合的に管理する。当初は個人での週10-20時間の開発・運用制限を考慮し、月商30万円を達成するためのMVPを構築し、段階的に機能を拡張していく。

## 3. 非機能要件

| 項目 | 要件 |
|------|------|
| 可用性 | MVP: ローカル/低価格クラウドで週10-20h稼働。Phase3: 99%以上 |
| セキュリティ | 機密情報は環境変数管理。Phase3: テナント間データ完全分離 |
| 性能 | 利益計算・価格最適化は3秒以内。スクレイピングはバックグラウンド実行 |
| 運用保守性 | 機能モジュール疎結合。外部障害時に半手動モードへ即時切替可能 |
| コスト | 初期100万円以内でAPI・インフラ・プロキシ費用最適化 |

## 4. 制約事項

### BUYMA規約遵守（違反 = アカウント停止）
- **禁止仕入れ先**: 国内公式オンライン、メルカリ等フリマアプリ
- **許可仕入れ先**: 海外オンライン（公式・セレクトショップ）、海外店舗、国内実店舗
- 18日以内発送（延長申請可能）
- 成約手数料 7.7%（国内ショッパー）

### 技術的制約
- スクレイピングはブロックリスク常時あり → 半手動フォールバック必須
- 海外公式サイトのBotアクセス禁止の可能性 → 利用規約確認必要
- 転送倉庫経由購入 → ブランド側の転売制限に抵触する可能性

### 開発制約
- ソロ開発、週10-20時間
- MVP優先、スモールスタート

## 5. 用語定義

| 用語 | 定義 |
|------|------|
| BUYMA | 海外ブランドアイテムの購入代行EC。個人ショッパーが調達・販売 |
| 無在庫転売 | 在庫を抱えず、購入確定後に仕入れるモデル |
| 18日ルール | BUYMA購入者への発送完了を18日以内に行う規則 |
| Bright Data | WebスクレイピングAPIサービス |
| 転送倉庫 | 海外購入品を日本へ転送するサービス（Stackry, Shipito等） |
| MVP | 実用最小限の製品。コア機能のみで早期運用検証 |
