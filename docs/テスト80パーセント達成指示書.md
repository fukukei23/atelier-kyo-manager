### 4. テスト作成ルール

1. **1ファイル = 1テストファイル**（対応する名前にする）
   - `app/utils/scout_currency.py` → `tests/test_scout_currency.py`

2. **構造**:
   ```python
   """Tests for app/utils/scout_currency.py"""
   import pytest
   from app.utils.scout_currency import ...

   class TestScoutCurrency:
       def test_convert_jpy_to_eur(self):
           result = convert_currency(1000, 'JPY', 'EUR')
           assert result > 0
   ```

3. **DBテスト**: `conftest.py` の `app` フィクスチャを使う
   ```python
   def test_model_persistence(self, app, db):
       with app.app_context():
           obj = Model(field='value')
           db.session.add(obj)
           db.session.commit()
           assert Model.query.count() == 1
   ```

4. **ルートテスト**: `client` フィクスチャを使う
   ```python
   def test_get_route(self, client):
       resp = client.get('/path')
       assert resp.status_code == 200
   ```

5. **外部APIは必ずモック化**:
   ```python
   from unittest.mock import patch, MagicMock

   @patch('app.utils.scout_currency.requests.get')
   def test_with_mock(self, mock_get):
       mock_get.return_value.json.return_value = {'rate': 150.0}
       ...
   ```

6. **Playwright/Seleniumは絶対モック化**（async汚染を防ぐ）
