# 商品管理

![商品管理]({{ site.baseurl }}/screenshots/02-products.png)

## 概要

仕入商品の登録・編集・CSV一括登録を管理。画像収集→AI背景除去→AI説明文生成の出品パイプラインをここから実行します。

## 機能のポイント

- **CRUD操作**: 商品の登録・編集・削除・一覧表示
- **CSV一括登録**: スプレッドシートから商品情報を一括インポート
- **出品パイプライン**: 1クリックで画像収集→背景除去→説明文生成→出品テキスト生成
- **画像管理**: 商品画像のアップロード・リサイズ・AI背景除去（rembg）

## 出品パイプラインの流れ

```
商品URL入力 → 画像収集(Scraper) → 背景除去(rembg) → AI説明文生成(LLM) → 出品テキスト生成
```

1. **画像収集**: 商品ページからPlaywrightで画像を自動取得
2. **背景除去**: rembg (U2-Net) で商品画像の背景を自動除去
3. **AI説明文生成**: OpenAI/Gemini APIで商品説明文を自動生成
4. **出品テキスト生成**: BUYMA出品用のフォーマットに自動変換

## 技術的詳細

- **パイプライン制御**: `pipeline_service.py` が各ステップを順次実行・エラーハンドリング
- **画像処理**: OpenCV + Pillow でリサイズ・色調整、rembgで背景除去
- **CSV処理**: pandas でCSV読み込み→バリデーション→DB一括登録
- **非同期対応**: 将来的にCelery+Redisでパイプラインの非同期化を計画
