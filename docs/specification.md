## 2. MVP機能の動作仕様

### FR-001 / FR-005 利益計算エンジン

#### 簡易計算 (FR-001 / 実装済み)
- **入力**: 仕入れ価格(USD/EUR)、為替レート、マークアップ率
- **計算式**: `販売価格 = 仕入れ価格 × 為替レート × マークアップ率(1.5)`
- **出力**: BUYMA販売価格(JPY)、利益額、利益率

#### 実ベース計算 (FR-005 / 未実装)
- **入力**: 仕入れ価格、通貨、転送倉庫送料(USD)、商品カテゴリ、BUYMA手数料(7.7%)
- **計算式**:
  ```
  課税価格 = 仕入れ価格(円換算) + 転送送料(円換算)
  関税 = 0                        (課税価格 ≦ 10,000円)
  関税 = 課税価格 × 関税率(10-20%) (課税価格 > 10,000円)
  総コスト = 課税価格 + 関税
  BUYMA手数料 = 販売価格 × 7.7%
  利益額 = 販売価格 - 総コスト - BUYMA手数料
  最低販売価格 = 総コスト / (1 - 0.077)
  推奨販売価格 = 最低販売価格 × 目標マークアップ(1.3)
  ```
- **出力**: 総コスト、最低販売価格、推奨販売価格、利益額、利益率
- **エラー処理**:
  - 為替レート取得不可 → 手動入力を促す
  - 数値以外 → バリデーションエラー
  - 販売価格がBUYMA上限超過 → 警告表示

### FR-006 18日ルール管理（未実装）

- **入力**: BUYMA注文ID、注文日、支払い方法
- **出力**: 発送期限日、残り日数、延長申請可否・上限、ステータス
- **延長上限**:

| 支払い方法 | 延長上限 |
|-----------|---------|
| クレジットカード / 楽天Pay | 45日 |
| d払い / au PAY / ペイディ | 25日 |
| コンビニ振込 / 銀行振込 | 90日 |

- **アラート段階**:

| 残り日数 | レベル | 表示色 | メッセージ |
|---------|--------|--------|-----------|
| 4日以上 | 注意 | 黄色 | 発送準備をお願いします |
| 2日 | 警告 | オレンジ | 期限が近づいています。延長申請を検討してください |
| 0日 | 危険 | 赤色 | 本日が期限です。至急発送または延長申請を |
| -1日以下 | キャンセル | 黒 | 期限切れ。キャンセル発生の可能性 |

### FR-004 BUYMA価格調査（部分実装）

- **入力**: キーワード / ブランド名 / 商品名
- **処理**: Bright Data経由でBUYMA検索結果をスクレイピング
- **出力**: 価格分布（最安・中央・最高）、出品者数、人気順位
- **フォールバック**: Bright Dataブロック（403/503）時 → 自動で手動入力モードに切替
- **エラー処理**:
  - スクレイピング失敗 → リトライ最大3回 → フォールバック
  - 検索結果0件 → 「該当商品が見つかりません」

---

### FR-002 / FR-003 画像・説明文生成（実装済み）

#### 画像処理フロー
1. 商品画像URL または ローカル画像を入力
2. AI背景除去（透明化 or 白背景化）
3. BUYMA推奨サイズ（800×800px等）に最適化・トリミング
4. プレビュー表示

#### 説明文生成フロー
1. 商品基本情報（ブランド・素材・サイズ・カラー）を入力
2. AI構造化テキスト生成（ブランド名・商品名・素材・サイズ・カラー・おすすめポイント）
3. 生成文プレビュー → 編集 → コピー

- **エラー処理**:
  - 低解像度画像 → 警告「画質が荒くなる可能性があります」
  - AI APIエラー → 「処理に失敗しました。時間をおいて再試行してください」

## 3. Phase 2機能の仕様概要

### FR-009 AI自動発注 & Slack通知
- **トリガー**: BUYMA注文確定
- **処理**: 仕入れ先URL → カート投入 → 決済 → 転送倉庫配送指定
- **通知**: Slack Webhook で進捗・エラーを通知
  - ステータス: `注文確定` / `カート投入完了` / `決済完了` / `エラー発生`
- **エラー処理**: 在庫切れ・サイト仕様変更 → 即座にSlackアラート → 手動へエスカレーション

### FR-010 AI ChatBot（顧客対応）
- **対応範囲**: 在庫の有無、サイズ実寸、発送目安、送料
- **処理**: 過去Q&A・商品データ参照 → 自動下書き/返答
- **エスカレーション**: クレーム・値引き交渉・未知の質問 → 人間へ通知
